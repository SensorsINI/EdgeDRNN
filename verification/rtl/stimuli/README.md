# Generated RTL stimuli

These files are generated by the native PyTorch export stage. The `.txt` names
and packed hexadecimal layout are part of the RTL verification interface.

- `manifest.json` describes the model, entry counts, and file hashes for tooling.
- `edgedrnn_tb_config.svh` provides fixed memory sizes to SystemVerilog.
- `edgedrnn_tb_{creg,params,stim,gold_rnn}.txt` feed the common testbench.
- `sigmoid_lut.txt` and `tanh_lut.txt` are generated activation tables.

Regenerate the complete set with:

```bash
python python/main.py --step export
```
